# Todo

This context tracks a person's todos in one private list, helping them keep track of what is still in progress and what is complete.

## Language

**할 일 (Todo)**:
A task tracked in the app, identified by its title and completion state. Two todos may have the same title and remain distinct items.
_Avoid_: Task

**진행 중**:
The state of a todo that the user has not marked complete.
_Avoid_: 미완료 항목

**완료**:
The state of a todo that the user has marked finished.
_Avoid_: Done
