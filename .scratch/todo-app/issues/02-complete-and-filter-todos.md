# 02: Todo 완료 처리와 상태 필터

**What to build:** 사용자가 Todo를 완료 또는 진행 중으로 바꾸고, 전체·진행 중·완료 상태별로 목록을 볼 수 있습니다.

**Blocked by:** 01: Todo 추가 및 목록 보기

**Status:** ready-for-agent

- [ ] Todo를 완료 상태로 전환하거나 다시 진행 중 상태로 되돌릴 수 있습니다.
- [ ] 전체, 진행 중, 완료 필터가 각각 해당 Todo만 표시합니다.
- [ ] 상태 변경이 저장되어 새로고침 후에도 유지됩니다.
- [ ] 각 필터에서 최신 생성 항목부터 표시합니다.
- [ ] 격리된 테스트 데이터베이스를 사용하는 브라우저 E2E 흐름으로 상태 전환, 복원, 필터 결과, 영속성을 확인합니다.
