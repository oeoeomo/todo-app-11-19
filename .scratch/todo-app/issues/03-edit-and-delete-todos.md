# 03: Todo 제목 수정 및 삭제

**What to build:** 사용자가 진행 중이거나 완료된 Todo의 제목을 수정하고, 확인 절차를 거쳐 영구 삭제할 수 있습니다.

**Blocked by:** 01: Todo 추가 및 목록 보기; 02: Todo 완료 처리와 상태 필터

**Status:** ready-for-agent

- [ ] Todo의 제목을 수정할 수 있으며, 앞뒤 공백 제거·빈 제목 거부·중복 제목 허용 규칙을 따릅니다.
- [ ] 진행 중 또는 완료 필터에 표시된 Todo를 수정하거나 삭제할 수 있습니다.
- [ ] 삭제 전 확인을 표시하고, 취소하면 Todo를 유지하며, 확인하면 해당 Todo를 영구 삭제합니다.
- [ ] 수정 및 삭제 결과가 저장되어 새로고침 후에도 유지됩니다.
- [ ] 격리된 테스트 데이터베이스를 사용하는 브라우저 E2E 흐름으로 제목 검증, 상태별 수정·삭제, 취소, 영구 삭제, 영속성을 확인합니다.
